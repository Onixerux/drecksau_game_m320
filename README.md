Drecksau
Ein strategisches Kartenspiel für 2-4 Spieler. Wer zuerst alle seine Schweine dreckig macht, gewinnt.

Spielziel
Mache alle deine eigenen Schweine so schnell wie möglich schmutzig, bevor es ein anderer Spieler schafft. Gleichzeitig kannst du die Schweine deiner Gegner sauber waschen oder ihre Ställe zerstören, um sie aufzuhalten. 
Der erste Spieler, dessen alle Schweine schmutzig sind, gewinnt das Spiel.

Spieleranzahl & Schweinekarten 
2 Player: 5 Schweinekarten 
3 Player: 4 Schweinekarten
4 Player: 3 Schweinekarten 

Karten (66 Karten total)
Schweinekarten
	- 12 Schweinekarten: Doppelseitige Karten - eine Seite sauber, eine Seite schmutzig. Zeigen den aktuellen Zustand eines Schweins
	
Eigene Karten (auf eigene Schweine spielen)
	- 21 Matschkarten: Macht ein eigenes Schwein schmutzig 
	- 9 Stallkarten: Baut einen Stall und schützt das Schwein vor Regen
	- 4 Blitzableiterkarten: Schützt dauerhaft vor Blitz - Stall kann nicht mehr abbrennen
	- 4 Bauer-ärgere-dich-Karten: Blockiert den Bauern - er kann dieses Schwein nicht putzen
	- 4 Wassereimerkarten: Löscht ein brennendes Haus, bevor Feuerschaden entsteht 

Angriffskarten (gegen Gegner spielen)
	- 4 Regenkarten: Macht alle Schweine ohne Stall wieder sauber. Löscht ausserdem ein brennendes Haus - verursacht aber trotzdem noch 1x Feuerschaden 
	- 8 Bauer-schrubbt-die-Sau-Karten: Macht ein Schwein eines Gegners wieder sauber (funktioniert auch bei Schweinen im Stall)
	- 4 Blitzkarten: Zerstört den Stall eines Gegners (wirkt nicht bei Blitzableiter)
	- 4 Feuerkarten: Zündet das Haus eines Gegners an. Jede Runde wird ein Upgrade zerstört bis das Haus abbrennt
	
Spezialregel: Glückliche Drecksau 
Wenn ein Schwein gleichzeitig folgende drei Karten hat: Stall, Blitzableiter, Bauer-ärgere-dich-Schutz
-> Das Schwein ist unantastbar und kann von keinem Gegner mehr beeinflusst werden 

Feuersystem
	- Eine Feuerkarte kann auf das Haus eines Gegners gespielt werden 
	- Im ganzen Spiel kann nur ein einziges Haus brennen. Erst wenn das Feuer gelöscht ist oder das Haus abbrennt, darf die Feuerkarte wieder eingesetzt werden 
	- Jedes Mal wenn der betroffene Spieler an der Reihe ist, wird ein Upgrade zerstört (z.B. Blitzableiter, Türen)
	- Wenn keine Upgrades mehr vorhanden sind, wird das Haus zerstört 
	- Mit der Wassereimerkarrte kann das Feuer gelöscht werden, bevor Schaden entsteht
	- Die Regenkarte löscht das Feuer ebenfalls, verursacht aber trotzdem einmalig 1x Feuerschaden, bevor es erlischt 

Spielablauf
	1. Vorbereitung
		- Jeder Spieler erhält seine Schweine (sauber)
		- Das Deck wird gemischt 
		- Jeder Spieler zieht 3 Handkarten 
		- Die restlichen Karten bilden den Nachziehstapel 
	2. Spielzug (im Uhrzeigersinn) Pro Runde macht ein Spieler eine der folgenden Aktionen:
	Option A - Karte auf eigenes Schwein legen:
		- Matschkarte, Stallkarte, Blitzableiterkarte, Bauer-ärgere-dich-Karte oder Wassereimerkarte
	Option B - Aktionskarte gegen Gegner spielen:
		- Regenkarte, Blitzkarte, Bauer-schrubbt-die-Sau-Karte oder Feuerkarte 
	3. Nach dem Zug
		- Die gespielte Karte kommt auf den Ablagestapel 
		- Der Spieler zieht ein neue Karte, sodass er wieder 3 Handkarten hat
		- Der nächste Spieler ist dran 
	4. Kann ein Spieler keine Karten spielen? Wenn kein Zug möglich ist (z.B. drei Blitzkarten, aber kein Gegner hat einen Stall):
		- Spieler zeigt seine Karten vor 
		- Alle Handkarten werden abgelegt 
		- Spieler zieht 3 neue Karten 
		- Zug endet sofort 
	5. Nachziehstapel leer?
		- Der Ablagestapel wird gemischt und wird zum neuen Nachziehstapel 

Siegbedienung 
Sobald alle Schweine eines Spielers schmutzig sind, endet das Spiel sofort. Dieser Spieler gewinnt!
